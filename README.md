# Lettres en Quête

Application Android (Godot 4) de six mini-jeux de lecture pour les 5-8 ans, sans compte ni serveur.

Tout le projet est dans le dossier [`android/`](android/) : voir [`android/README.md`](android/README.md)
pour l'ouvrir dans Godot, lancer les tests et fabriquer l'APK, et [`android/CREDITS.md`](android/CREDITS.md)
pour les licences des modèles 3D.
