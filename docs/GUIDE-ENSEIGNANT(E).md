# Atelier Lecture — Guide rapide

## Première installation

1. Télécharge le fichier ZIP depuis GitHub.
2. Clique droit sur le fichier, puis « Extraire tout ».
3. Ouvre le dossier extrait.
4. Double-clique sur `INSTALLER.bat`.
5. Si Node.js est demandé, installe Node.js 20 LTS depuis https://nodejs.org.
6. Relance `INSTALLER.bat`.
7. Attends le message « Installation terminée ».

## Chaque séance

1. Allume le PC.
2. Connecte le PC au Wi-Fi de l’école.
3. Double-clique sur `DEMARRER.bat`.
4. Laisse la fenêtre noire ouverte.
5. Note l’adresse affichée, par exemple : `https://192.168.1.50:3000`.
6. Connecte les tablettes au même Wi-Fi.
7. Ouvre cette adresse dans Chrome sur chaque tablette.

## Après la séance

1. Sur le PC, ouvre l’Espace enseignant.
2. Choisis un élève.
3. Consulte ses séances et ses résultats.
4. Double-clique sur `SAUVEGARDER.bat`.
5. Ferme ensuite la fenêtre noire.

## Si cela ne fonctionne pas

- Vérifie que le PC et les tablettes sont sur le même Wi-Fi.
- Vérifie que la fenêtre noire est toujours ouverte.
- Vérifie que l’adresse affichée dans la fenêtre noire est bien celle ouverte sur la tablette.
- Si le Wi-Fi tombe, les élèves peuvent terminer leur séance : les résultats seront envoyés plus tard.
